# 📚 Learning Notes · 学习笔记仓库

个人学习成长轨迹仓库：记录每天的学习内容、代码练习与刷题进度，**保持持续提交，见证长期积累**。

## 仓库结构

```
learning-notes/
├── README.md            # 本页：仓库总览
├── docs/                # 文档与学习日志（每日记录模板见 learning-log.md）
├── java/                # Java 后端学习笔记
├── algorithms/          # 算法 / 刷题记录
├── notes/               # 各类学习笔记与总结
└── code/                # 可运行的代码练习
```

## 使用约定

1. 每次学习 / 写代码，先在 `docs/learning-log.md` 追加一条日志（见模板）。
2. 学完立刻 `git commit` + `git push`，让提交记录随学习同步增长。
3. 笔记重要结论尽量附可追溯来源，区分「已查证」与「个人理解」。

## 提交规范

- `feat:` 新增内容 / 代码
- `docs:` 笔记、文档、日志
- `fix:` 修正错误
- `refactor:` 重构

## 成长目标

> 不追求单次的大工程，只求每天一小步、持续在线。
